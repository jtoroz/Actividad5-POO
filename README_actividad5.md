## Contenido

Codificación en Python, con interfaz gráfica de usuario en Tkinter, de los siguientes ejercicios del libro *Ejercicios de programación orientada a objetos con Java y UML* de Leonardo Bermón Angarita:

- Ejercicio 8.4 (página 517) - Cuadros de diálogo: programa Nómina
- Ejercicio 8.5 (página 546) - Gestión de contenido: programa Hotel

## Ejecución

Los programas abren ventanas de escritorio, por lo que deben ejecutarse localmente:

```
python actividad5_ej84_nomina.py
python actividad5_ej85_hotel.py
```

En Google Colab no funcionan, porque es un entorno sin interfaz gráfica.

En ambos programas las acciones se encuentran en el menú **Opciones** de la ventana principal.
